# LifeOS — инструкция для Claude

Работаю с Дмитрием. Отвечаю кратко, по-русски. Всё, что ему нужно прочитать,
пишу в финальном сообщении: текст между вызовами инструментов он не видит.

## С чего начать новый чат

1. Прочитать `ARCHITECTURE.md` — как устроено приложение (одна задача, четыре окружения, две системы).
2. Прочитать `ROADMAP.md` — этапы до финала.
3. Прочитать `BACKLOG.md` — раздел «Сейчас» (где остановились) и список починки.
4. Подготовить среду (раздел ниже) и коротко сказать Дмитрию, где мы и что следующее.

## Как работаем

- По умолчанию — режим планирования, без реализации.
- «баг, чини» → чиню сразу. Просто «баг» → записываю в `BACKLOG.md`, чиню пачкой по команде.
- «покажи, как будет выглядеть» → картинка и объяснение, без реализации.
- Любую правку сначала проверяю в Playwright, потом пушу в GitHub. Пуша без зелёных тестов нет.
- Артефакт на claude.ai не публикую: приложение живёт на GitHub Pages.

## Среда

- Клон: `git clone --depth 1 https://github.com/dmitry-aleshkevich/lifeos /home/claude/lifeos`
- Тесты ждут путь `/home/claude/work/lo`: `mkdir -p /home/claude/work && ln -sfn /home/claude/lifeos /home/claude/work/lo`
- v1: исходники `src/shell.html`, `src/app.css`, `src/js/*.js`.
- v2 (бета): `v2/index.html`.
- **Тесты гонять по чистой сборке:** `python3 build.py`, затем `cd tests && ./run_tests.sh`.
  Сборка с Supabase (`build_gh.py`) без сети падает и валит все тесты.
- **Перед пушем:** `python3 build.py && python3 build_gh.py index.html`, затем commit и push в `main`.
- test63 падает и на старом коде. 40, 41, 43, 44, 52, 66 иногда мигают — перезапустить по одному.

## Команда «идём в новый чат»

Когда Дмитрий это говорит:

1. Обновить в `BACKLOG.md` раздел «Сейчас»: что сделано в этом чате, на чём остановились,
   следующий шаг, открытые вопросы к Дмитрию.
2. Отметить в `ROADMAP.md`, на каком мы этапе. Если менялась архитектура — обновить `ARCHITECTURE.md`.
3. Незаконченные правки: либо довести до зелёных тестов и запушить, либо откатить —
   в репозитории не должно оставаться полуготового кода.
4. Commit и push.
5. Дать Дмитрию стартовое сообщение для нового чата (ниже) и одну строку о том, где мы.

Стартовое сообщение:

> Продолжаем LifeOS. Подключи репозиторий dmitry-aleshkevich/lifeOs, прочитай CLAUDE.md и начни с раздела «Сейчас» в BACKLOG.md.
